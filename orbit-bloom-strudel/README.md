# Orbit Bloom Strudel

Strudel-focused music + visual playground, separated from the original `orbit-bloom` project.

## Run

From `/Users/magbicaleman/tiiny-stuff/orbit-bloom-strudel`:

```bash
npx serve .
```

Then open:

- <http://localhost:3000>

## Notes

- Click `Start Beat` to unlock audio and start playback.
- This project layers multiple Strudel tracks and maps each track to different visual behaviors.
- Music-theory and synthesis guidance for agents is in `AGENTS.md`.
