Prompt 01

Start by asking for a system, not a single logo.

Original prompt

Transform this image into a grid of minimalist logos using the main subject as the core icon. Abstract and simplify the primary element into multiple unique vector-style logo marks.

Each variation should reinterpret the same subject in different ways: geometric, line art, negative space, emblem, badge, monogram. Arrange 16-20 logos evenly on a light background.

Follow-up: “Let’s use a kitten as the source inspiration.”

Result 01

The icon grid created usable brand DNA.

Why it worked

It produced options with a shared visual language.

The output had enough range to choose from: solid marks, line icons, badges, negative-space cats, and simple face symbols. One of those marks became the anchor for the next prompt.

Prompt 02

Use the logo result as context for a landing page.

Follow-up prompt

“Can you design a landing page for a cat recording studio and pick one of icons you created, let’s make the main colors yellow, and accent black, give it space, and give it life.”

Prompt 03

The typo that drove itself into the campaign.

Follow-up prompt

“Can you now make a magazine add with a photorealist ad for PurrTone that’s emotional maybe hybrid of a real image of a car with anime eyes or something like that.”

Cat brand, car prompt

I meant cat. I typed car. The model did exactly what I asked and put a moody black car in the ad. Prompt typo, premium parking spot.

The funny part is that it still followed the brand direction: black and yellow, studio signage, emotional headline, soundwave energy, and the PurrTone mark.

Result 03

The fix: change one letter, change the whole hero.

Original typo car

The model followed the prompt literally and built the ad around a black car.

Corrected intent cat

The fixed direction brings the hero back to PurrTone’s original cat-led brand idea.
